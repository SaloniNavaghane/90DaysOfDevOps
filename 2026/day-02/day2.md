# Process states

## created: the process is created
## Ready: Waiting to turn on CPU
## Running: Process is in execution
## waiting: waiting for next input
## stopped: The Process is paused stopped according user input we can also say it terminated
## zombie: the process is completed but the parents process is yet to complete so this process is in process table
## orphan: Parents have completed the execution but the child is yet to complete so it is reparented to init process(as parent)
